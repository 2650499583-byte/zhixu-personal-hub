# 知序 · 个人信息管家

一个把零散信息整理成清晰行动的个人信息工作台。记录想法、资料、链接和待办，应用会自动分类、提取重点，并把相关内容连接起来。

## 功能

- **快速记录**：想法、资料、链接、待办统一入口，自动判断类型并归类
- **自动整理**：生成摘要、提取重点、推荐标签，与已有内容建立关联
- **关键词检索**：按内容与标签匹配，支持按类型、分类、收藏筛选
- **智能问答**：基于已有内容作答，并附上引用来源，可直接跳回原文
- **待办管理**：识别「明天」「周五」等时间表达，区分优先级，支持完成与重开
- **阶段回顾**：按周/月生成总结、内容分布与后续行动建议
- **数据自主**：JSON 备份导出与合并导入，示例内容可一键清除

## 技术栈

React 19 · Vite 6 · lucide-react，无后端依赖。

## 本地运行

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # 生产构建
npm start        # 读取 PORT，绑定 0.0.0.0（用于部署）
```

## 数据与能力边界

- 记录保存在**浏览器 localStorage**，不上传服务器，不同设备/浏览器之间不同步
- 分类、摘要、重点提取、关联、检索问答与阶段总结由**内置规则**完成，未接入云端大模型
- 内置 9 条示例内容用于演示，可在首页提示条或「数据与存储」中一键清除
- 清除浏览器数据前请先导出备份

```
│   ├── intelligence.js  分类、摘要、关联、检索问答、回顾生成

└── pages/               概览 / 全部内容 / 待办 / 助手 / 回顾
```
